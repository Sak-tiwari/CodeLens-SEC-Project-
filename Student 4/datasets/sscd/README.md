# SSCD industrial C clone dataset (dataset_c)

Source: https://github.com/SFI-Lero/SSCD (dataset-01/dataset_c), MIT licence (see LICENSE).
80 known C clone pairs (77 function-level, 3 sub-function-level). `dataset_c.csv` lists, per pair,
the two source files and the line ranges of the clone fragments. Used only to validate the
similarity algorithms (Experiment 5).
